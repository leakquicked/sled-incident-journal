# СЛЕД — журнал расследования

Локальный инструмент для учебного разбора журналов безопасности. Сводит записи в временную линию, помогает находить совпадения и сохранять ход анализа.

**Открыть приложение:** [leakquicked.github.io/sled-incident-journal](https://leakquicked.github.io/sled-incident-journal/)  
**Запуск без публикации:** скачайте `index.html` и откройте его в современном браузере.

## Возможности

- Импорт JSON, JSONL/NDJSON и CSV, а также вставка записей из буфера.
- Поиск по событию, узлу, IP-адресу, субъекту, источнику и MITRE ATT&CK ID.
- Фильтрация по уровню и источнику события.
- Карточка события и сопоставление записей по общим узлу, адресу или субъекту.
- Экспорт набора событий в JSON и сводного отчёта в Markdown.
- Заметки аналитика с сохранением в локальном хранилище браузера.
- Адаптивная тёмная тема, не требующая сборки и сторонних библиотек.

## Формат данных

Распознаются распространённые варианты полей:

| Поле | Варианты |
| --- | --- |
| Время | `time`, `timestamp`, `@timestamp`, `date` |
| Уровень | `severity`, `level`, `priority` |
| Событие | `event`, `name`, `action`, `message` |
| Узел | `host`, `hostname`, `device`, `computer` |
| IP-адрес | `ip`, `src_ip`, `source_ip`, `client_ip` |
| Источник | `source`, `product`, `service`, `log_source` |
| Субъект | `actor`, `user`, `username`, `account` |
| MITRE ATT&CK | `mitre`, `technique`, `mitre_id` |
| Описание | `summary`, `description`, `details` |

Пример записи:

```json
{
  "time": "2025-03-18T08:42:11Z",
  "severity": "high",
  "event": "Неудачная аутентификация",
  "host": "workstation-17",
  "ip": "192.0.2.14",
  "source": "Windows",
  "actor": "analyst@example.test",
  "mitre": "T1110",
  "summary": "Синтетический пример события."
}
```

Поддерживаются уровни `critical`, `high`, `medium`, `low`, `info` и русские эквиваленты.

## Набор для проверки

В [examples/synthetic-injection-chains.json](./examples/synthetic-injection-chains.json) лежат 120 синтетических событий по 10 учебным цепочкам: SQL, command, template, LDAP, HTML, path, SSRF, XML, заголовки и NoSQL. Импортируйте файл кнопкой **«Импортировать журналы»**.

Вместо рабочих эксплойтов используются инертные canary-маркеры. Адреса взяты из документационных диапазонов RFC 5737, домены — из `.test`; сетевые обращения и выполнение кода отсутствуют. Один HTML canary использует безопасный текстовый тег для проверки экранирования в интерфейсе.

## Конфиденциальность и границы применения

Журналы обрабатываются в браузере и не отправляются приложением на сервер. Заметки хранятся в `localStorage` текущего браузера. Перед импортом реальных журналов учитывайте, что в них могут содержаться персональные данные и секреты. Не загружайте такие данные в публичные репозитории.

Демонстрационные записи синтетические. Сопоставление основано на совпадении полей и не является детектированием угроз. «СЛЕД» не заменяет SIEM, EDR или экспертное расследование и не формирует автоматический вердикт.
